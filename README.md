# Medien Lernen

Interaktive Lern-App fuer die Ausbildung Medienfachfrau: Grafik, Print, Publishing und audiovisuelle Medien.

## iPad Art Tracker

Der Ordner `ipad-art/` enthaelt eine zweite kleine Web-App fuer Video-Unterricht zu Procreate, Illustrator und Photoshop auf dem iPad. Sie speichert Fortschritt und Notizen lokal im Browser und kann ebenfalls ueber GitHub Pages geoeffnet werden:

`https://kristikus18.github.io/medien-lernen/ipad-art/`

## 4 Monate Portfolio Trainer

Der Ordner `portfolio-4-months/` enthaelt eine neue Lern-App mit 16 Wochen, 2 Lerntagen pro Woche und Portfolio-Projekten fuer Illustrator, InDesign, Photoshop, Figma, WordPress und Elementor. Jede Woche hat eine andere feste Kundenrichtung, einen konkreten Auftrag, Umfang, Seitenzahl/Formate, Abgabe, Fachwoerter und Lernfortschritt.

`https://kristikus18.github.io/medien-lernen/portfolio-4-months/`

## GitHub Pages

Diese App ist ein statischer Webordner. Fuer die Veroeffentlichung auf GitHub Pages:

1. Dateien aus diesem Ordner in ein GitHub-Repository hochladen.
2. In GitHub `Settings` > `Pages` oeffnen.
3. Als Quelle `Deploy from a branch` waehlen.
4. Branch `main` und Ordner `/root` auswaehlen.
5. Speichern und die Pages-URL oeffnen.

Die App kann danach am iPhone in Safari geoeffnet und zum Home-Bildschirm hinzugefuegt werden.
