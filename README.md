# Medien Lernen

Interaktive Lern-App fuer die Ausbildung Medienfachfrau: Grafik, Print, Publishing und audiovisuelle Medien.

## GitHub Pages

Diese App ist ein statischer Webordner. Fuer die Veroeffentlichung auf GitHub Pages:

1. Dateien aus diesem Ordner in ein GitHub-Repository hochladen.
2. In GitHub `Settings` > `Pages` oeffnen.
3. Als Quelle `Deploy from a branch` waehlen.
4. Branch `main` und Ordner `/root` auswaehlen.
5. Speichern und die Pages-URL oeffnen.

Die App kann danach am iPhone in Safari geoeffnet und zum Home-Bildschirm hinzugefuegt werden.
