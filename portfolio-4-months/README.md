# 4 Monate Portfolio Trainer

Neue Lern-App fuer Krystyna Lozova. Die alte App im Repository bleibt unveraendert.

Pfad fuer GitHub Pages:

`https://kristikus18.github.io/medien-lernen/portfolio-4-months/`

## Konzept

- 4 Monate
- 16 Wochen
- 2 Lerntage pro Woche
- Theorie und Praxis zusammen
- Portfolio-Projekte statt isolierte Uebungen
- Adobe, Figma, WordPress und Elementor
- kurze kostenlose YouTube-Tutorials als Einstieg

## Schwerpunkt

Der Plan basiert auf den Pruefungsthemen aus `THEORIE MEDIEN.pdf`, aber jede Theorie wird direkt in ein Projekt uebersetzt:

- Logo
- Visitenkarte
- Flyer
- Broschuere
- Social Media Kampagne
- Landing Page in Figma
- WordPress/Elementor Umsetzung
- Behance Case Study
- Portfolio PDF
